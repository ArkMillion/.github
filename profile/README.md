## 🧰 What We're Building

Everything we do starts from problems we actually ran into while building our own products. All of it lives right here on GitHub.

### [ArkCrossPlayerData](https://github.com/ArkMillion/ArkCrossPlayerData)

Designed for Minecraft server networks that need reliable player state synchronization across multiple servers, built on Fabric.

- Redis distributed locks + optimistic version control prevent conflicting writes
- Seamless player state transfer between servers

`Java` `Fabric` `Minecraft` `Redis`

### [DataManager](https://github.com/ArkMillion/DataManager) ![Stars](https://img.shields.io/github/stars/ArkMillion/DataManager?style=social&label=%E2%AD%90)

A zero-Spring data access layer for Java — one lightweight library, works with any framework.

- One consistent API over **MySQL, PostgreSQL, SQLite, MongoDB & Redis**
- Annotation-driven schema sync & versioned SQL migrations out of the box
- No Spring dependency — designed for standalone Java applications and game servers

`Java` `Persistence` `SQL` `NoSQL` `Apache-2.0`

### [Arks-Translate](https://github.com/ArkMillion/Arks-Translate)

An AI-assisted English reading tool that translates PDFs while preserving the original layout — built for anyone who needs to read and understand technical documents, not just quick machine translation.

`Python` `AI` `PDF`
